# Release checklist

This standalone project uses the MIT license selected in this repository. Before tagging a release, confirm ownership or redistribution rights for the retained code, procedural artwork, generated assets and tests, and add any required third-party notices. MicroPython, Pimoroni firmware and optional desktop dependencies have their own licenses and are not bundled here.

No original Git history, remote configuration, credentials or connected services are included. Wi-Fi setup, NTP, web controls, HTTP uploads and remote update/rollback code are removed. Updates use USB.

Complete the physical acceptance checks in VALIDATION.md, record tested firmware and measured frame rate, then review and merge the draft PR. Tag the accepted snapshot (for example v0.1.0) and attach a source ZIP. The original project repository remains unchanged.
